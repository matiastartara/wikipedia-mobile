Appium project using Java and Testng on wikipedia apk

**Prerequisites**

Java 11 installed 

Intellij Idea

Appium Desktop App


**Installation**

1-Clone repository 

2-Open project and import maven dependencies

3-Open config.properties file and check these properties :

-device.android.name 

-run.ip

-run.port

**Test Execution** 

To run the tests select xml files under suite folder.
